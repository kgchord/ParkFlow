# ParkFlow

FASTag (UHF RFID) + ANPR fusion on an on-site Edge Node for stop-free, token-free parking in India.
Vishwakarma Awards 2026-27, Stage 2 engineering package (prototype: the "ParkFlow Demo Lane").

**Status (25 Oct 2026): design stage. No hardware has been built or bench-tested yet.** Performance figures are targets or predictions to be bench-verified, unless a log in the repo shows a measured run. Billing goes to a mock NETC ledger; no real FASTag debit is attempted.

## Layout

| Folder | What is in it |
|---|---|
| `docs/` | Stage 1 concept, problem and journey, safety/FMEA, risks, roadmap, firmware notes, open decisions, references |
| `cad/openscad/` | Parametric OpenSCAD models (gantry, Edge Node enclosure, barrier, occupancy node, lane layout) |
| `cad/renders/`, `cad/dxf/`, `cad/stl/` | Preview renders, laser-cut profiles, printable parts |
| `cad/step/` | STEP interchange files generated by script from the same parameters |
| `cad/calcs/`, `cad/fea/` | Hand calculations and CalculiX/gmsh FEA decks, logs, figures |
| `cad/freecad/` | Rebuild guide and parameter spreadsheet generator for FreeCAD |
| `electronics/` | System design specification, pin map, KiCad schematic and placement-only PCB, ERC/DRC reports, diagrams |
| `firmware/` | Lane Controller (ESP32-S3) state machine and Edge Node fusion software, with host tests and logs |
| `bom/` | Priced bill of materials workbook (vendors in Delhi NCR, Bengaluru, Chennai, Mumbai) and notes |

## Reproduce

- Firmware tests: `./firmware/run_all.sh`
- FEA: `cad/fea/scripts/run_all.sh` (needs CalculiX and gmsh)
- STEP: `python3 cad/step/build_step.py` (needs CadQuery)
